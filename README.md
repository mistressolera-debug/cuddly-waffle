# cuddly-waffle

Static site for [monarchofthemoon.shop](https://monarchofthemoon.shop), the Monarch of the Moon family-friendly shop, hosted on GitHub Pages.

- `index.html`: current "Shop launching soon" page
- `assets/`: images, styles, scripts
- `products/`: product pages and data (planned: Stripe checkout + Printful/Printify fulfillment)
- `legal/`: shipping, returns, privacy, terms (planned)
- `CNAME`: custom domain (do not change)
